## 🧑‍💻 Sobre mim

Olá! Sou estudante de **Análise e Desenvolvimento de Sistemas no Instituto Federal de São Paulo (IFSP)**.

Atualmente, estou direcionando meus estudos para o desenvolvimento de aplicações **Back-end** e **Engenharia de Dados**, buscando construir soluções que unam programação, tecnologia e inteligência de dados.

Tenho interesse em desenvolver sistemas, trabalhar com bancos de dados, automatizar processos e transformar dados em informações relevantes.
